# Evaluation

We use **Exact Match** as evaluation metric following [ToG-2](https://github.com/DataArcTech/ToG-2).

The experimental results are generated by the main program `CoG/main.py` and stored in the `CoG/results` directory (by default).

## Usage

You can evaluate the results using the `eval.py` script. There are two ways to specify the results to evaluate: by **Experiment ID** or by **Output File Path**.

Result files may be JSON or JSONL. Each result must contain a `question` string and an `answer` string.

### Arguments

- `--dataset`: The dataset name (e.g., `KGQAGen`, `cwq`, `qald`, `webqsp`, `2wiki`, `hotpot_e`, `musique`). Default is `hotpot_e`.
- `--experiment_id`: The experiment ID (folder name) located in `../CoG/results`. The script will automatically look for `summary_light_results.json` inside this folder.
- `--output_file`: The direct path to the result JSON file.
- `--data_question_string`: The key to access the question text in the output file (default: `question`).

### Examples

#### 1. Evaluate CoG Results using Experiment ID (Recommended)

If you have run `CoG/main.py` and have an experiment ID (e.g., `251225_202218_hotpot_e_Qwen3-32B_bge-m3`), you can simply provide it:

```bash
python eval.py \
  --experiment_id 251225_202218_hotpot_e_Qwen3-32B_bge-m3 \
  --dataset 2wiki
```

#### 2. Evaluate CoG Results using Output File Path

You can also directly point to the result file generated by CoG:

```bash
python eval.py \
  --output_file ../CoG/results/251225_202218_hotpot_e_Qwen3-32B_bge-m3/summary_light_results.json \
  --dataset 2wiki
```

#### 3. Evaluate ToG-2 Results (External File)

If you are evaluating results from another system (like ToG-2) or a file in a different location:

```bash
python eval.py \
  --output_file <path_to_ToG-2>/shot-Qwen3-32B-hotpot_e-bge-bi-w3d3s10sw1_TP_RC.json \
  --dataset hotpot_e
```
